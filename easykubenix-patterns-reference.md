# EasyKubenix Setup and Kubernetes Patterns Reference

## 1. EasyKubenix Structure

### Module Organization
- Main configuration: `/etc/nixos/kubernetes/default.nix`
- Module definitions: `/etc/nixos/kubernetes/modules/`
- Deployment system: `/etc/nixos/modules/services/k8s-nix-deploy.nix`

### easykubenix Module Import Pattern
```nix
cluster = import ./cluster.nix;
easykubenix = import inputs.easykubenix {
  inherit pkgs;
  modules = [
```

### Cluster Constants (`cluster.nix`)
Shared constants available to all K8s modules via `_module.args.cluster`:
```nix
# /etc/nixos/kubernetes/cluster.nix
{
  subnet = "10.1.1.0/24";
  podCidr = "10.244.0.0/16";
  hosts = {
    zephyr.ip = "10.1.1.110";
    nexus.ip  = "10.1.1.120";
    forge.ip  = "10.1.1.130";
    sentry.ip = "10.1.1.140";
  };
  kubernetes = { vip = "10.1.1.100"; apiPort = 6443; };
}
```
Usage in modules: `{cluster, ...}: { /* use cluster.subnet, cluster.podCidr */ }`

### Boot Sequence (k8s-secret-bootstrap → k8s-nix-deploy → casdoor-app-sync)
1. `k3s.service` starts
2. `k8s-secret-bootstrap.service` — auto-generates K8s secrets if missing
3. `k8s-nix-deploy.service` — applies all Nix-managed K8s manifests
4. `casdoor-app-sync.service` — syncs Casdoor application config with generated secrets

### Secret Management
- **NEVER** define K8s Secret objects in Nix modules — `kubectl apply` would overwrite real values
- Secrets are auto-generated by `k8s-secret-bootstrap` on first deploy
- On existing deploys, bootstrap detects existing secrets and skips
- Configure in host services.nix: `services.k8s-secret-bootstrap.secrets`

## 2. Naming Conventions & Labels

### Managed Label Pattern
```nix
managed = {
  "app.kubernetes.io/managed-by" = "easykubenix";
};
```

### Component Labels Pattern
```nix
metadata.labels = managed // {
  "app.kubernetes.io/component" = "controller";  // or "ui", "database", etc.
};
```

### Application Labels Pattern
```nix
metadata.labels = managed // {
  app = "haven";  // or "mission-control", "grafana", etc.
};
```

### Namespace Labels Pattern
```nix
metadata.labels = managed // {
  name = "haven";
  "pod-security.kubernetes.io/enforce" = "baseline";
  "pod-security.kubernetes.io/audit" = "restricted";
  "pod-security.kubernetes.io/warn" = "restricted";
};
```

## 3. Common Resource Patterns

### Namespace Definition
```nix
none.Namespace.${namespace} = {
  metadata.labels = {
    name = namespace;
    "pod-security.kubernetes.io/enforce" = "baseline";
    "pod-security.kubernetes.io/audit" = "restricted";
    "pod-security.kubernetes.io/warn" = "restricted";
  } // managed;
};
```

### Service Account Pattern
```nix
${namespace}.ServiceAccount.${name} = {
  // Optional: disable token mounting for UI pods
  automountServiceAccountToken = false;
};
```

### Secret Pattern
```nix
${namespace}.Secret.${name} = {
  type = "Opaque";
  stringData = {
    client-id = "...";
    cookie-secret = "...";
    // Add other secret values
  };
};
```

### ConfigMap Pattern
```nix
${namespace}.ConfigMap.${name} = {
  metadata.labels = managed;
  data = {
    CONFIG_KEY = "value";
    "nginx.conf" = builtins.readFile ./nginx.conf;
    // Add other config values
  };
};
```

### Persistent Volume Claim Pattern
```nix
${namespace}.PersistentVolumeClaim.${name} = {
  metadata.labels = managed // {"app.kubernetes.io/component" = "database";};
  spec = {
    accessModes = ["ReadWriteOnce"];
    storageClassName = "local-path";  // or "fast-local-ssd"
    resources.requests.storage = "2Gi";
  };
};
```

## 4. Deployment Patterns

### Basic Deployment Structure
```nix
${namespace}.Deployment.${name} = {
  metadata.labels = managed // {"app.kubernetes.io/component" = "component";};
  spec = {
    replicas = 1;
    revisionHistoryLimit = 2;
    selector.matchLabels = {"app.kubernetes.io/component" = "component";};
    template = {
      metadata.labels = {"app.kubernetes.io/component" = "component";};
      spec = {
        nodeSelector."kubernetes.io/hostname" = targetNode;
        serviceAccountName = "${name}";
        securityContext = {
          runAsNonRoot = true;
          seccompProfile.type = "RuntimeDefault";
        };
        containers._namedlist = true;
        containers.${name} = {
          image = "${registry}/${repository}:${tag}";
          imagePullPolicy = "IfNotPresent";
          ports._namedlist = true;
          ports.http = {containerPort = 8080; protocol = "TCP";};
          env._namedlist = true;
          env = {
            ENV_VAR.value = "value";
            PASSWORD.valueFrom.secretKeyRef = {name = "${name}-secret"; key = "password";};
          };
          envFrom = [{configMapRef.name = "${name}-config";}];
          resources = {
            requests = {cpu = "200m"; memory = "256Mi";};
            limits = {cpu = "500m"; memory = "512Mi";};
          };
          securityContext = {
            readOnlyRootFilesystem = true;
            allowPrivilegeEscalation = false;
            capabilities.drop = ["ALL"];
            seccompProfile.type = "RuntimeDefault";
          };
          startupProbe = {
            httpGet = {path = "/health"; port = 8080;};
            periodSeconds = 15;
            initialDelaySeconds = 15;
            failureThreshold = 10;
          };
          readinessProbe = {
            httpGet = {path = "/health"; port = 8080;};
            periodSeconds = 30;
          };
          volumeMounts._namedlist = true;
          volumeMounts.data = {mountPath = "/data";};
        };
        volumes._namedlist = true;
        volumes.data.persistentVolumeClaim.claimName = "${name}-data";
      };
    };
  };
};
```

### Deployment with Database Dependency
```nix
// PostgreSQL with StatefulSet
${namespace}.StatefulSet.${name} = {
  metadata.labels = managed // {"app.kubernetes.io/component" = "database";};
  spec = {
    serviceName = "${name}";
    replicas = 1;
    selector.matchLabels = {"app.kubernetes.io/component" = "database";};
    template = {
      metadata.labels = {"app.kubernetes.io/component" = "database";};
      spec = {
        nodeSelector."kubernetes.io/hostname" = targetNode;
        serviceAccountName = "${name}";
        securityContext = {
          fsGroup = 999; runAsUser = 999; runAsGroup = 999;
          runAsNonRoot = true;
          seccompProfile.type = "RuntimeDefault";
        };
        containers._namedlist = true;
        containers.${name} = {
          image = "postgres:18.3-alpine";
          imagePullPolicy = "IfNotPresent";
          ports._namedlist = true;
          ports.postgresql = {containerPort = 5432; protocol = "TCP";};
          env._namedlist = true;
          env = {
            POSTGRES_DB.value = "${name}";
            POSTGRES_USER.value = "${name}";
            POSTGRES_PASSWORD.valueFrom.secretKeyRef = {name = "${name}-secret"; key = "POSTGRES_PASSWORD";};
          };
          resources = {requests = {cpu = "250m"; memory = "256Mi"}; limits = {cpu = "500m"; memory = "512Mi"};};
          livenessProbe = {
            exec.command = ["pg_isready" "-U" "${name}" "-d" "${name}"];
            initialDelaySeconds = 20; periodSeconds = 10; timeoutSeconds = 5; failureThreshold = 6;
          };
        };
        volumeClaimTemplates = [{
          metadata.name = "data";
          spec = {
            accessModes = ["ReadWriteOnce"];
            storageClassName = "local-path";
            resources.requests.storage = "2Gi";
          };
        }];
      };
    };
  };
};
```

## 5. Service Exposure Patterns

### ClusterIP Service (Internal Only)
```nix
${namespace}.Service.${name} = {
  metadata.labels = managed // {"app.kubernetes.io/component" = "component";};
  spec = {
    type = "ClusterIP";
    selector = {"app.kubernetes.io/component" = "component";};
    ports._namedlist = true;
    ports.http = {port = 8080; targetPort = 8080; protocol = "TCP";};
  };
};
```

### NodePort Service (External Access)
```nix
${namespace}.Service.${name} = {
  metadata.labels = managed // {app = "app-name";};
  spec = {
    type = "NodePort";
    selector.app = "app-name";
    ports._namedlist = true;
    ports.http = {
      port = 3000;
      targetPort = 3000;
      nodePort = 32102;  // Range 32100-32199
      protocol = "TCP";
    };
  };
};
```

### Service Discovery URLs
- Cluster internal: `http://${service-name}.${namespace}.svc.cluster.local:${port}`
- External via NodePort: `http://${node-ip}:${nodePort}`

## 6. Ingress and Routing Patterns

### Caddy Configuration for Services
The cluster uses Caddy as TLS ingress. Routes are defined in `/etc/nixos/hosts/zephyr/caddy-routes.nix`:

#### Public Routes (No Auth)
```nix
mkRoute "ai.lan" "http://127.0.0.1:1237" +
mkRoute "searxng.lan, search.lan" "http://searxng.search.svc.cluster.local:8080" +
mkRoute "vaultwarden.lan" "http://vaultwarden.infra.svc.cluster.local:8222"
```

#### Protected Routes (SSO Auth)
```nix
mkAuthRoute "haven.lan" "http://127.0.0.1:32100" +
mkAuthRoute "kagent.lan" "http://kagent-controller.kagent.svc.cluster.local:8083"
```

### NodePort Allocation Pattern
- Range: 32100-32199
- Examples:
  - haven: 32100
  - mission-control: 32101
  - grafana: 32102
  - vaultwarden: 32111
  - openwebui: 32080

## 7. Storage Patterns

### Persistent Volume Claims
```nix
// Local Storage
storageClassName = "local-path"

storageClassName = "fast-local-ssd"
```

### Persistent Volumes (Node-local)
```nix
none.PersistentVolume.${name} = {
  spec = {
    capacity.storage = "5Gi";
    accessModes = ["ReadWriteOnce"];
    persistentVolumeReclaimPolicy = "Retain";
    storageClassName = "fast-local-ssd";
    local.path = "/data/${name}";
    nodeAffinity.required.nodeSelectorTerms = [{
      matchExpressions = [{
        key = "kubernetes.io/hostname";
        operator = "In";
        values = ["nexus"];
      }];
    }];
  };
};
```

### Host Path Volumes
```nix
volumes.nix = {
  hostPath.path = "/nix";
  type = "Directory";
};
```

## 8. Network Policies

### Default Deny
```nix
${namespace}.NetworkPolicy.default-deny-${namespace} = {
  spec = {
    podSelector = {};
    policyTypes = ["Ingress"];
  };
};
```

### Allow Ingress (using cluster constants — NO hardcoded IPs)
```nix
{cluster, ...}: {
  config.kubernetes.objects = {
    ${namespace}.NetworkPolicy.allow-ingress-${namespace} = {
      metadata.labels = managed;
      spec = {
        podSelector.matchLabels = {"app.kubernetes.io/part-of" = "app";};
        policyTypes = ["Ingress"];
        ingress = [
          {from = [{namespaceSelector.matchLabels.name = "ingress-system"}]; ports = [{protocol = "TCP"; port = 8080;}];}
          {from = [{ipBlock.cidr = cluster.podCidr;}]; ports = [{protocol = "TCP"; port = 8080;}];}
          {from = [{ipBlock.cidr = cluster.subnet;}]; ports = [{protocol = "TCP"; port = 8080;}];}
        ];
      };
    };
  };
}
```

### Allow Egress
```nix
${namespace}.NetworkPolicy.allow-egress-${namespace} = {
  metadata.labels = managed;
  spec = {
    podSelector.matchLabels.app = "app";
    policyTypes = ["Egress"];
    egress = [
      {to = [{ipBlock.cidr = "0.0.0.0/0"}]; ports = [{protocol = "UDP"; port = 53;} {protocol = "TCP"; port = 53;}];}
    ];
  };
};
```

## 12. Example Deployments

### Kagent (Full-Stack Application)
- Namespace: kagent
- Components: Controller, UI, PostgreSQL
- Services: All ClusterIP
- Node affinity: nexus
- Network Policies: Ingress from ingress-system, cluster-cidr, lan
- RBAC: ClusterRole/ClusterRoleBinding for wide permissions

### Haven (Simple NodePort Service)
- Namespace: haven
- Components: Single deployment
- Service: NodePort 32100
- hostNetwork: true (for port mapping)
- PVC for data persistence

### Grafana (Monitoring Service)
- Namespace: monitoring
- Service: NodePort 32102
- Deployment with persistent volume for dashboards
- NetworkPolicy from ingress-system
